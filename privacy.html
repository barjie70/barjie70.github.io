Privacy Policy — Personal Cloud Archive Purpose Personal Cloud Archive is a private application operated for personal use. It uses Rclone to manage encrypted backups and archival data stored in the operator’s Google Drive account. Information Accessed The application accesses Google Drive through Google’s OAuth 2.0 authentication system. Depending on the operations performed, this includes: * File and folder names and metadata. * File contents required for uploading or downloading. * Google Drive account access tokens required for authentication. How Information Is Used Information is used exclusively to: * Upload encrypted archival files. * Retrieve and restore archived files. * List and manage files stored in the designated Google Drive account. Encryption and Security Files are encrypted locally using Rclone Crypt before being uploaded to Google Drive. The application does not intentionally transmit unencrypted archival file contents to third parties. OAuth credentials are stored locally on the operator’s computer. Information Sharing The application does not sell, share or distribute personal information or archived file contents for advertising, marketing or commercial purposes. Data Retention Archived files remain in Google Drive until the operator chooses to remove them. Revoking Access Google Drive access can be revoked at any time through Google Account security settings. Contact This application is operated solely for personal use and is not a public service.
